# Keyple Logging Android Log JVM Library

## Overview

The **Keyple Logging Android Log JVM Library** provides an Android Log-based implementation of the
Keyple logging abstraction layer defined
in [Keyple Util Java Lib](https://github.com/eclipse-keyple/keyple-util-java-lib).
It allows Keyple components to integrate seamlessly with the Android logging system
(android.util.Log), enabling applications to leverage Android's native logging infrastructure
including Logcat for debugging and monitoring.

## Documentation & Contribution Guide

The full documentation, including the **user guide**, **download information** and **contribution
guide**, is available on the Keyple website [keyple.org](https://keyple.org).

## API documentation

API documentation & class diagram is available
online: [docs.keyple.org/keyple-logging-android-log-jvm-lib](https://docs.keyple.org/keyple-logging-android-log-jvm-lib)

## About the source code

The code is built with **Gradle** and is compliant with **Java 1.8** in order to address a wide
range of applications.

## Continuous Integration

This project uses **GitHub Actions** for continuous integration. Every push and pull request
triggers automated builds and checks to ensure code quality and maintain compatibility with the
defined specifications.
